# 项目环境需求

> 记录「AI Drama 群聊剧情模拟」的运行环境基线，以及「📂 浏览→选择知识库文件夹」对话框的
> 实现方式与对应环境依赖。本文档对应前后端同机部署（`http://127.0.0.1:8008`）。

## 一、运行基线

| 组件 | 要求 | 备注 |
|---|---|---|
| 操作系统 | **跨平台**（Windows / macOS / Linux） | 核心功能与平台无关；仅「📂 浏览」原生文件夹选择**需 Windows 桌面会话**，其他平台手填路径 |
| Python | **≥ 3.10**（推荐 3.12+；开发机 3.14 / 镜像 3.12） | 后端 FastAPI / uvicorn / httpx，需能 `pip install -r requirements.txt` |
| 前端 | 原生 HTML/CSS/JS | 无需构建工具；由 FastAPI 静态托管，浏览器访问 |
| 数据库 | 无 | 会话/记忆为本地 JSON 落盘（`data/`，可用 `AIDRAMA_DATA_DIR` 改） |
| LLM | 任意 OpenAI 兼容服务 | 默认 DeepSeek `https://api.deepseek.com`；Key 用环境变量或 UI 配置，**必填** |
| Docker（可选） | Docker + Compose v2 | **非必需**；`docker compose up --build` 一键起服务，容器内「📂 浏览」不可用 |
| 端口 | 默认 8008 空闲 | 冲突时启动加 `--port 其它端口` |

## 二、知识库文件夹选择对话框的环境依赖

### 采用方案（当前实现）：系统自带 `powershell.exe` + IFileDialog（无需额外安装）

- 浏览器因安全限制无法提供所选文件夹的**磁盘绝对路径**，故「📂 浏览」由**同机后端**
  （`POST /api/kb/native-pick`）弹系统对话框并取回绝对路径。
- 本方案使用 **Windows 自带 `powershell.exe`（5.1，.NET Framework）**：
  - `Add-Type` 编译一段极简 C#，封装 COM `IFileOpenDialog`，开启
    `FOS_PICKFOLDERS | FOS_FORCEFILESYSTEM`；
  - 弹出**资源管理器风格**文件夹选择窗口（顶部有地址栏 / 可编辑路径输入框、左侧导航）；
  - 用 `GetDisplayName(SIGDN_FILESYSPATH=0x80058000)` 取绝对路径。
- **无需安装任何额外软件**（这正是本机不装 PowerShell 7 也能用现代对话框的原因）。
- 验证命令（该 C# 必须能在 `powershell -STA` 下 `Add-Type` 编译通过）：
  ```powershell
  powershell -NoProfile -STA -Command "Add-Type -TypeDefinition <C#>; [ModernFolderPicker]::Pick('选择知识库目录')"
  ```

### 备选方案（未采用）：PowerShell 7 + `Microsoft.Win32.OpenFolderDialog`

- `.NET 8` 提供 WPF 的 `Microsoft.Win32.OpenFolderDialog`（同样是资源管理器风格、顶部带路径输入框），
  但需 **PowerShell 7（内置 .NET 8）** 才行；Windows 自带的 `powershell.exe 5.1` 没有此类型。
- 本机现状：**无 `winget`、无 `pwsh`**；且 **GitHub 直连下载需手动配置代理**（本项目为 GitHub 配过代理，
  但本机环境变量无代理由 cmd 直连下行 CDN 会超时）。故此处不采用、也不强装。
- 若日后要启用，安装途径：
  - 有 `winget` 的机器：`winget install --id Microsoft.PowerShell`
  - 无 winget：从 GitHub Releases 下载 `PowerShell-7.x-win-x64.msi` 静默安装
    `msiexec /i ... /qn /norestart`（需管理员），或解压便携版 `...-win-x64.zip`（免管理员，
    记得配代理后再下载）。
  - `Microsoft.Win32.OpenFolderDialog` 的 PowerShell 调用：
    ```powershell
    Add-Type -AssemblyName PresentationFramework
    $d = New-Object Microsoft.Win32.OpenFolderDialog; $d.Title = "选择知识库目录"
    if ($d.ShowDialog()) { [Console]::Write($d.FolderName) }
    ```

## 三、为什么前端不能直接弹系统对话框

- `<input type="file" webkitdirectory>` 能弹系统文件夹选择 UI，但**只返回文件夹内文件的相对路径**，
  浏览器**刻意不提供所选文件夹的绝对路径**；
- 本后端需要的是服务端磁盘上的**绝对路径**，因此必须由**同机后端**弹原生对话框并在进程内拿到路径，
  再回填给前端。

## 四、对应实现位置

- 后端：`backend/main.py` → `POST /api/kb/native-pick`（内含该段 C# / 调用 PowerShell 的载荷）。
- 前端：`frontend/index.html` + `frontend/app.js` → 「📂 浏览」按钮 → 调 `/api/kb/native-pick`，
  失败（含未安装/无桌面）则 tips 报错。
- 相关接口文档：`开发文档/API接口参考.md`。
