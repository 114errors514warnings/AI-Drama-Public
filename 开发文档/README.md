# AI Drama · 群聊剧情模拟系统 — 开发文档总述

## 一、项目简介

一个基于 **DeepSeek（OpenAI 兼容接口）** 的多 Agent 群聊剧情模拟系统，实现了需求文档
《群聊剧情模拟说明文档.md》中 **V1–V4** 的全部功能，并提供完整 Web UI 交互。

- **项目目录**：`<项目目录>`
- **默认端口**：8008（原 8000 被 SillyTavern 占用，故改用 8008）
- **技术栈**：Python 3.14 + FastAPI + uvicorn + httpx（LLM 直连）/ 原生 HTML+CSS+JS 前端
- **知识库**：任意目录均可作为"一个世界"的知识库（**无默认路径**，创建会话时手动选择，
  可用路径框右侧「📂 浏览」预览并选择）；按 **Character / Memory / World** 三文件夹读取，
  `Character/`=角色档案、`Memory/`=角色初始长期记忆、`World/`=世界观背景（缺失自动新建）

## 二、版本功能总览

| 版本 | 阶段 | 具体功能内容 |
|---|---|---|
| **初版** | 完整实现 | ① V1 动态角色 Agent（角色识别→知识库检索→Prompt 组装→角色回复，含单角色对话模式）；② V2 Agent Registry（每角色独立 Agent 实例：资料/情感/关系/长期记忆，Character Factory 实例化）；③ V3 Runtime Manager（create/destroy/pause/resume 生命周期，UI 可操作）；④ V4 世界模拟（Director 导演调度群聊、World Agent 一致性校验可开关、Timeline 时间线、Event 事件流、Memory Manager 长短记忆）；⑤ RAG 知识库检索（角色名匹配 + 世界观关键词检索注入角色上下文）；⑥ 多会话并行隔离（一个知识库 = 一个世界 = 一套独立 Agent 集合）；⑦ 角色记忆持久化（data/sessions/<会话>/characters/<角色>.json，切换/重启不丢失）；⑧ 群聊 Web UI（气泡界面、会话列表、Agent 面板、世界面板、模型配置）；⑨ API Key 安全（仅内存、只返回掩码） |
| **迭代1** | 启动与端口管理 | ① `start.bat` / `start.ps1` 一键启动（自动检测 Python、自动装依赖、延迟打开浏览器）；② 默认端口 8000→8008（SillyTavern 占用）；③ `stop.bat` / `stop.ps1` 停止脚本（按端口查进程并结束）；④ `本机端口清单` 端口清单记录 |
| **迭代2** | 问题修复 | ① "创建群聊 Failed to fetch"修复：页面顶部离线红色横幅 + 友好中文错误提示 + 每 10 秒自动重连；② 群聊中导演以独立身份"导演"发言（场景描述归属导演），角色强制第一人称对白（禁止第三人称旁白式描写他人），世界校验/交代事项不再写入转录与记忆（场外因素彻底隔离）；③ 输入框固定底部、消息区独立滚动（grid 行高锁定 100vh + min-height:0，修复整页随对话滚动） |
| **迭代3** | 功能增强 | ① 人物详情查看（点击角色卡片弹出弹窗：完整档案/情感/关系/长期记忆/技能）；② 会话设置弹窗（重命名、查看知识库/世界/消息数、清空对话记录保留记忆、删除群聊二次确认） |
| **迭代4** | 配置增强 | ① API Key 界面设置（密码框 + 显示/隐藏切换）；② Base URL 可配置；③ 配置持久化到 `data/config.json`（不写回 本地 Key 文件）；④ 「测试连接」按钮（发一次极小请求验证 Key）；⑤ 启动加载优先级：本地配置 > 本地 Key 文件 |
| **迭代5** | 功能增强 | ① 剧情梗概（Synopsis Agent 节流更新，每累计 6 条消息自动生成，可手动"🔄 更新"）；② 时间格式（默认年月日如 `2026年8月30日`，可切换"年月日+时间段/相对故事时间"；无日期时显示回退文案"时间未定"） |
| **V2** | 正式产品化 | ① 移除前端 "V1-V4" 徽标；② 人物长期记忆编辑 UI（记忆管理弹窗 + `PUT /character/memory` 写接口，含增删改/去重/落盘/System Prompt 重建）；③ 角色命名通用化（角色名以文档文件名为准、文档标题降级为别名用于匹配，接口统一改用 query 参数传名，根治"角色名含 `/` 404"问题，存量会话自动迁移）；④ GitHub 发布（仓库 `AI-Drama`，排除脚本与敏感数据，配置代理与凭据缓存） |


## 五、安全约定

1. **API Key 永不外泄**：完整 Key 只保存在内存与本地 `data/config.json` 中；
   接口、日志、前端与本文档一律只出现掩码（如 `sk-****…****`），Key 仅从浏览器单向提交给后端。
2. **场外因素不污染角色**：导演调度 JSON、世界校验结果、记忆抽取指令等"场外"内容
   绝不写入共享群聊转录与角色记忆库，只从角色本人对白中抽取长期记忆。
3. **世界隔离**：不同群聊会话 = 不同知识库 = 不同 Agent 集合与记忆文件，互不干扰。
