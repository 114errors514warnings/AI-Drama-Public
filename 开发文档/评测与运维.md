# AI Drama · 评测与运维（V3 迭代）

> 本文档说明本轮的「可观测 / 可评测 / 可交付」能力与门禁口径。

## 1. 三层测试

| 层 | 命令 | 内容 |
|---|---|---|
| L1 功能/单元 | `python -m pytest -q` | 记忆治理、世界日期单调、指标口径、会话/世界观隔离、导演闭环、API 冒烟 |
| L2 阶段门禁 | `python -m backend.eval.replay` | 确定性 FakeLLM 固定剧本回放 20 轮，统计硬指标并判定 |
| L3 部署冒烟 | `docker compose up --build` | 真实起服务，经 `/api/...` 调用验证 |

退出码：`0` = 全 PASS；`1` = 存在 FAIL（可直接作 CI 门禁）。

## 2. 指标口径（`backend/metrics.py`）

| 指标 | 定义 | 门禁 | 类型 |
|---|---|---|---|
| `agent_orchestration_success_rate` | 完整跑通的轮次 / 总轮次 | ≥ 0.98 | 硬 |
| `offscreen_leak_count` | 转录中出现场外内容特征/非法角色的条数 | = 0 | 硬断言 |
| `world_violation_rate` | 世界校验发现问题的轮次 / 总轮次 | ≤ 0.05 | 硬 |
| `world_correction_rate` | 被自动修正的违规 / 总违规（enforce 模式） | = 1.0（有违规时） | 机制 |
| `timeline_issues` | 事件流因果问题数（日期回退/时段倒流/空事件/重复） | = 0 | 硬 |
| `synopsis_coverage` | 梗概对已发生事件的覆盖度 | 观察项 | 观测 |
| `memory_usage_rate` | 记忆召回率代理（发言与长期记忆的词面重叠比例） | 观察项 | 观测 |
| `avg_tokens_per_turn` / `p95_turn_latency_ms` | 单轮 token / 延迟 | 观察项 | 观测 |
| `persona_consistency` | LLM 裁判人设一致率（多采样取均值） | 观察项（`in_gates=false`） | 观测 |
| `memories_total` / `characters_active` / `events` | 规模观测 | 观察项 | 观测 |

LLM 裁判类指标（人设一致率等）**只作观察项**，多采样取均值，不进硬门禁（避免方差污染）。
所有门禁口径集中在 `backend/metrics.py`，硬门禁集合为 `metrics.GATES`。

## 3. 数据落盘

```
data/sessions/<会话ID>/
├── session.json        # 会话元信息 + 世界状态 + 时间线 + 梗概 + 梗概基线长度
├── transcript.json     # 群聊完整记录（短期记忆来源）
├── turns.jsonl         # 每轮编排明细（Agent 调用图 / 耗时 / token / 违规与修正）← 新增
└── characters/<名>.json # 角色专属：资料 + 情感 + 关系 + 长期记忆
```

## 4. 不变量（硬断言）

1. **场外隔离**：世界校验反馈、记忆抽取指令、导演调度备忘、单 Agent 场外对话，
   一律**不写入** `transcript.json` 与角色记忆。
2. **会话隔离**：一个会话 = 一个知识库 = 一套独立 Agent 集合，跨会话互不可见。
3. **时间单调**：故事日期只进不退。
4. **记忆治理**：近重复合并、同值冲突保留较新、上限 80 条。

## 5. Docker

```bash
docker compose up --build
# → http://127.0.0.1:8008

docker compose run --rm app python -m backend.eval.replay
# → reports/replay_<时间戳>.md / .json
```

容器内 API Key 通过挂载的 `data/config.json`（`api_key` / `base_url` / `model`）提供，
`data/` 会持久化到宿主机。
