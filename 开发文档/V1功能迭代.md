# 迭代1：启动脚本与端口管理

## 背景
- 初版需手敲 `uvicorn` 命令启动，不便；且 8000 端口被 SillyTavern（Docker）占用。

## 实现
1. **start.bat**：一键启动（纯 ASCII，兼容所有 Windows）
   - 自动定位 Python（支持 `python` / `py -3`）；
   - 首次运行自动 `pip install -r requirements.txt`；
   - 启动后延迟 4 秒自动打开浏览器；
   - 支持自定义端口：`start.bat 8009`。
2. **start.ps1**：PowerShell 版，中文界面提示（UTF-8 BOM 保证中文不乱码），
   支持 `.\start.ps1 -Port 8009`。
3. **stop.bat / stop.ps1**：停止脚本
   - 通过 `netstat -ano` 定位监听指定端口的 PID 并 `taskkill /F`；
   - 无进程时给出提示。
4. **默认端口改为 8008**：8000 被 SillyTavern 占用；8008 已确认空闲。
5. **端口占用排查**：`netstat -ano` + 进程识别 + HTTP 标题探测，
   将全部占用端口用途记录到 `本机端口清单`（SilTtavern 8000 / Open WebUI 3000 /
   AstrBot 6185+6199 / OpenClaw 18789 / FlClash 7890 / QQ / WPS / Steam / YunShu / MSI / 360 等）。

## 涉及文件
`start.bat`、`start.ps1`、`stop.bat`、`stop.ps1`、`本机端口清单`

## 验证
- start.bat / start.ps1 均实测启动成功并自动打开浏览器（日志可见页面加载请求）；
- stop.ps1 实测停止服务器并释放端口；stop.bat 实测输出"Nothing is running"。

# 迭代2：问题修复

## 2.1 创建群聊失败 "Failed to fetch"

### 背景
页面已打开但服务器被停止后，点击「创建群聊」会报晦涩的 `Failed to fetch`。

### 实现
1. 前端 `api()` 捕获网络错误并抛出明确中文提示：
   "无法连接服务器：服务未启动或已停止。请先运行 start.bat…"；
2. 页面顶部新增红色**离线横幅** `#server-status`，断连即显示；
3. 每 10 秒心跳检测 `checkServer()`，服务器恢复后自动隐藏横幅、
   重载会话并提示"服务器已重新连接"。

### 涉及文件
`frontend/index.html`、`frontend/app.js`、`frontend/style.css`

## 2.2 群聊中导演独立发言 + 角色第一人称 + 场外因素隔离

### 背景
- 群聊中只有人物回复，导演只在幕后调度，且角色回复模仿导演的第三人称旁白腔；
- 世界校验（场外核对）被写入共享转录，污染所有角色上下文与记忆。

### 实现
1. **导演成为一等公民发言者**：场景描述以 `speaker="导演"` 写入转录，
   `_history` 中导演旧发言以「导演」为前缀供其识别；前端渲染为带头像"导"+名字"导演"的紫色气泡；
2. **角色第一人称化**（`build_character_system_prompt` 新增规则 7-9）：
   以第一人称「我」对白；禁止第三人称旁白式描写他人表情/心理；可用「（动作/神态）」简短补充；
3. **场外隔离**：World Agent 校验结果不再写入转录（仅返回调试字段
   `world_check_issues`）；记忆抽取明确"只提取角色本人所说/经历/承诺，旁白/场景/他人发言不记为角色记忆"；
4. 导演 Prompt 明确"「导演」前缀消息是导演自己之前的场景描述，其余角色发言与导演无关"。

### 涉及文件
`backend/prompts.py`、`backend/director.py`、`frontend/app.js`、`frontend/style.css`

### 验证
- 转录：`narrator | 导演 | 下午放学后，夕阳斜照在操场上…`；
- 角色回复第一人称：`B：A？她怎么来了……嘿，A。今天没被伯母留堂？`；
- 开启世界校验后转录无"世界校验"字样（污染=False）；
- 记忆只抽角色自己的话（B记住了"与A有关于测试的约定"）。

## 2.3 输入框固定、消息区独立滚动

### 背景
对话变多后整个界面一起滚动，输入框被顶出可视区。

### 根因
`#app` 是 grid 容器，只定义列宽与 `height:100vh`，**未定义行高**；
隐式行默认 `auto` 被内容撑高，`.chat` 高度超过视口，导致整页滚动，
`.messages` 的 `min-height:0` 因父级无确定高度而失效。

### 实现（前端 CSS）
```css
#app { display:grid;
       grid-template-columns:250px minmax(0,1fr) 320px;
       grid-template-rows:100vh;   /* 行高锁定 = 视口高度 */
       overflow:hidden; }
.sidebar, .chat, .panel { min-height:0; }
.messages { flex:1 1 0; min-height:0; overflow-y:auto; }
```
效果：只有消息区内部滚动，输入框固定底部，左右栏固定。

### 涉及文件
`frontend/style.css`

# 迭代3：人物详情与会话管理

## 3.1 人物详情查看

### 背景
角色卡片只显示 150 字档案预览，无法查看完整档案、情感、关系、长期记忆。

### 实现
1. **后端**：新增 `GET /api/sessions/{sid}/characters/{name}`，返回
   `name / status / profile(全文) / emotion_state / relationships / long_memory / skills / world_name`，
   支持角色别名解析（如"C"→"C / 代号C"）；
2. **前端**：角色卡片可点击（或「📄 详情」按钮）弹出人物详情弹窗，分区展示
   角色资料（全文）/ 情感状态 / 人际关系 / 长期记忆 / 技能。

### 涉及文件
`backend/main.py`、`frontend/index.html`、`frontend/app.js`、`frontend/style.css`

### 验证
A详情：status=active、档案全文 5692 字符、记忆条数正确返回。

## 3.2 会话设置 / 删除

### 背景
删除群聊藏在悬停 ✕ 上不显眼，且无重命名/清空能力。

### 实现
1. **后端**：
   - `PATCH /api/sessions/{sid}`：重命名；
   - `POST /api/sessions/{sid}/clear`：清空对话记录并重置世界时间线（**保留角色长期记忆**）；
   - 删除沿用 `DELETE /api/sessions/{sid}`（连带记忆，二次确认）。
2. **前端**：会话列表每项新增 ⚙ 设置按钮，弹窗支持
   重命名 / 查看知识库路径与统计 / 清空对话（确认）/ 删除群聊（红色+确认）。

### 涉及文件
`backend/main.py`、`backend/session.py`（`rename`/`clear_transcript`）、
`frontend/index.html`、`frontend/app.js`、`frontend/style.css`

# 迭代4：API Key 与配置

## 背景
初版 API Key 只能从 md 文件读取，UI 无法设置；配置重启后丢失。

## 实现
1. **后端 `config.py`**：
   - 新增本地持久化 `data/config.json`（含 api_key/base_url/model/temperature/
     world_check/time_format/time_fallback），**不写回用户的 本地 Key 文件**；
   - 启动加载优先级：`data/config.json` > `本地 Key 文件`（兜底）；
   - `Config.update()` 支持热更新并自动保存。
2. **后端 `main.py`**：
   - `POST /api/config` 扩展 `api_key` / `base_url` / `time_format` 等字段；
   - 新增 `POST /api/config/test`：用当前 Key 发一次极小请求验证连通性；
   - 安全：`GET /api/config` 始终只返回**掩码**，完整 Key 仅"浏览器→后端"单向传递。
3. **前端**：左侧配置面板新增
   - API Key 输入框（密码型 + 👁 显示/隐藏切换）；
   - Base URL 输入框（默认 `https://api.deepseek.com`）；
   - 「保存配置」「测试连接」按钮；Key 状态区显示掩码。

## 涉及文件
`backend/config.py`、`backend/main.py`、`frontend/index.html`、`frontend/app.js`

## 验证
- 配置保存后 `data/config.json` 持久化成功（字段齐全，api_key 长度 35、仅掩码展示）；
- 连接测试成功：DeepSeek 回复"你好！我是 DeepSeek…"；
- 完整 Key 未在任何接口/日志/前端出现。

# 迭代5：剧情梗概与时间格式

## 5.1 剧情梗概（Synopsis Agent）

### 背景
前端缺少对整体剧情进展的梗概。

### 实现
1. **后端**：`WorldState` 新增 `synopsis` + `synopsis_base_len`（随 session 持久化）；
   `DirectorAgent.update_synopsis()`：把"已有梗概 + 最近对话"合并为 150~300 字梗概，
   **节流每累计 6 条新消息自动更新**（`threshold=6`），群聊/单角色每轮后调用；
   新增 `POST /api/sessions/{sid}/synopsis` 手动强制刷新；
   `GET /api/sessions/{sid}/world` 返回 `synopsis`。
2. **前端**：世界面板顶部新增「📋 剧情梗概」卡片 +「🔄 更新」按钮。

### 涉及文件
`backend/world.py`、`backend/director.py`、`backend/prompts.py`、
`backend/main.py`、`frontend/index.html`、`frontend/app.js`、`frontend/style.css`

### 验证
群聊一轮后梗概："放学后，A邀请B和C一起去示例中学门口的小吃摊吃晚饭……
三人关系在轻松氛围中带着微妙的试探……"

## 5.2 时间格式（年月日）

### 背景
初版时间是无格式自由文本（"第 1 天 · 白天"、"下午放学后"），要求统一为年月日，
提供格式选项，无时间时显示回退文案。

### 实现
1. **后端 `world.py`**：结构化时间 `date`（ISO）+ `time_of_day`（白天/傍晚/晚上）；
   `display_time(fmt, fallback)` 统一格式化：
   - `date`（默认，年月日）：`2026年8月30日`
   - `datetime`（年月日+时段）：`2026年8月30日 傍晚`
   - `relative`（相对故事时间）：`第 12 天 · 傍晚`
   - 日期为空时返回 `fallback`（默认 `"时间未定"`）；
   `to_dict`/`restore` 兼容旧会话迁移（旧自由文本回落为起始日期）。
2. **后端 `director.py` + `prompts.py`**：导演 JSON 改为输出
   `date`（年月日，不跨天保持）+ `time_of_day`；`_normalize_date()` 统一为 ISO。
3. **配置**：新增 `time_format`（默认 `date`）与 `time_fallback`（默认 `时间未定`），
   持久化并可在 `GET/POST /api/config` 读写。
4. **前端**：配置面板新增「时间格式」下拉（年月日 / 年月日+时间段 / 相对故事时间）；
   各显示处（世界面板、聊天标题、时间线）统一读后端格式化后的 `time`；
   前端兜底 `|| "时间未定"`。

### 涉及文件
`backend/world.py`、`backend/director.py`、`backend/prompts.py`、
`backend/session.py`、`backend/config.py`、`backend/main.py`、
`frontend/index.html`、`frontend/app.js`

### 验证
- 新建会话无日期 → 显示"时间未定"；
- 群聊后导演设定日期 → 显示 `2026年8月30日`（时间线同步）；
- 切换格式：`第 1 天 · 白天` / `2026年8月19日` 均正确；
- 旧会话「示例世界」平滑迁移，无报错。
