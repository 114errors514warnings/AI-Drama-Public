# 校园生活

> 本文件放在 `World/背景/`，属于**常驻世界观**：每一轮对话都会注入角色提示词。

这是一所普通的城市高中，时间是春天，学期初。

- **场景**：教学楼、操场、图书馆、食堂、天台、校门口的小卖部与公交站。
- **节律**：早读 → 上午四节课 → 午休 → 下午两节课 → 社团活动 → 放学。
  午休和放学后是学生最自由的两段时间。
- **氛围**：没有超能力、没有超自然事件，一切以现实校园生活为准。
  重点是青春期学生之间的相处：友情、别扭、误解、和好、暗恋、考试压力、社团去留。
- **季节与天气**：春末，多阵雨；傍晚常有晚霞，操场会有蝉声（初夏将至）。
- **校园规则之外**：学生之间有自己的默契——谁和谁闹别扭了、谁在偷偷准备什么，
  这些不写在公告栏上，靠日常观察。

## 世界基调（给导演的提示）
- 剧情推进要"小"：一顿午饭、一次值日、一场练习赛，都能是推进。
- 冲突以"误会、别扭、说漏嘴"为主，不用极端事件。
- 不要引入犯罪、暴力、超自然等超出校园基调的元素。
