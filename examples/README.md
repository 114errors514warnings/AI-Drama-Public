# 示例知识库与模板

本目录提供**可直接使用**的示例知识库，以及可复制的角色卡模板。全部人名为合成（A / B / C），与任何真实作品无关。

## 目录

```
examples/
├── README.md                 # 本文件
├── character-template.md     # 角色卡模板（复制到你的 Character/ 下改名即可）
└── demo-kb/                  # 示例知识库（校园生活 · 角色 A/B/C）
    ├── Character/            # 角色卡（人设）
    │   ├── A.md
    │   ├── B.md
    │   └── C.md
    ├── Memory/               # 角色初始长期记忆
    │   └── A.md
    └── World/
        ├── 背景/校园生活.md   # 常驻世界观
        ├── 规则/校园规则.md   # 常驻硬规则
        ├── 词条/社团活动.md   # 关键词触发的世界观词条（Lorebook）
        └── 文风/文风规范.md   # 全局文风（去 AI 腔）
```

## 知识库约定

一个知识库 = 一个世界 = 一套互相隔离的角色与记忆。

| 目录 | 内容 | 说明 |
|---|---|---|
| `Character/` | 角色档案（人设） | **按文件名归档**为对应角色；文件名即角色名，可含 `/`、括号等任意字符 |
| `Memory/` | 角色初始长期记忆 | 按文件名对应角色；创建角色时读取，一行一条 |
| `World/背景/` `World/规则/` | 常驻世界观与硬规则 | 每轮都会注入提示词 |
| `World/词条/` | 关键词触发的世界观词条 | 命中当前对话关键词时才注入（front matter 写 `keys`） |
| `World/文风/`（或顶层 `Style/`） | 全局文风规范 | 未配置时用系统内置默认 |
| `World/写作辅助`、`评判标准`、`风格相关`、`草稿`、`大纲`、`模板`、`名录`、`README` | **永不注入** | 供人工参考，不会污染角色提示词 |

> 只建了 `Character/` `Memory/` `World/` 也能用；`World/背景`、`World/词条`、`World/文风` 是可选增强（建立后自动启用"常驻 + 词条"机制）。

## 用示例知识库跑起来

1. 启动服务（见仓库根 `README.md`）。
2. 左侧「＋ 新建群聊」→ 会话名随意。
3. **知识库路径**填 `examples/demo-kb` 的**绝对路径**（例如 `D:\code\ai-drama\examples\demo-kb`）。
4. 在左侧「模型配置」里填入你自己的 API Key（DeepSeek 或任意 OpenAI 兼容服务）。
5. 回群聊输入一句话，导演会自动调度 A/B/C 依次发言。

> 注意：路径要指向**这个目录本身**（里面直接是 `Character/` `Memory/` `World/`），不要再套一层。

## 做一个自己的角色卡

1. 复制 `character-template.md` 到你的知识库 `Character/` 下，改名成角色名，例如 `Character\小D.md`。
2. 按模板填写：**性格核心 / 关键标签 / 人物气质 / 语言风格 / 对话示例 / 关系 / 禁忌**。
3. 其中 **`语言风格` 和 `对话示例` 是"去 AI 腔"最有效的两项**——给 2~4 组真实对话示例，角色的说话方式会立刻像人。
4. 只写自由文本也行（不填小节）：系统会把整篇当作角色资料，但不会有示例带来的语感提升。
